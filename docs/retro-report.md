## What didn't go well 💥

### 🔴 High priority

#### R1 — No tests (unit or E2E)
**Impact:** Refactoring is risky. Can't verify features work after changes.
**Root cause:** No test framework set up (Jest, Playwright).
**Action:** Add Jest + React Testing Library (unit), Playwright (E2E).

#### R2 — No CSRF protection on API routes
**Impact:** API routes vulnerable to CSRF attacks.
**Root cause:** NextAuth v4 protects `/api/auth/*` but custom routes (`/api/boards`) don't have CSRF checks.
**Action:** Add CSRF token validation or use `getServerSession()` on every API route.

#### R3 — Pagination missing on `GET /api/boards`
**Impact:** Slow response for users with 100+ boards.
**Root cause:** API returns all boards without pagination.
**Action:** Add `?limit=20&offset=0` pagination.

### 🟡 Medium priority

#### R4 — No caching layer
**Impact:** Every GET request hits DB directly. Slow for high traffic.
**Root cause:** No Redis/cache layer.
**Action:** Add `Cache-Control` headers or use SWR on client.

#### R5 — `console.error` in production code
**Impact:** Noise in browser console. Should use proper logging service.
**Root cause:** Error handling uses `console.error` (acceptable for now, but should migrate to Sentry).
**Action:** Add Sentry or LogRocket for error monitoring.

#### R6 — Date formatting hardcoded to `en-US`
**Impact:** Chinese users see English date format.
**Root cause:** `toLocaleDateString("en-US")` ignores user locale.
**Action:** Use `undefined` (browser locale) or `zh-CN`.

### 🟢 Low priority (nice to have)

#### R7 — No dark mode support
**Impact:** Users who prefer dark mode get eye strain.
**Root cause:** App is light-only.
**Action:** Add `next-themes` + `dark:` Tailwind classes.

#### R8 — No health check endpoint
**Impact:** Vercel can't do health checks.
**Root cause:** No `/api/health` endpoint.
**Action:** Add `GET /api/health` returning `{ status: "ok" }`.
